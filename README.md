# ImgCompressor & Formatter 🚀

A high-performance, fully offline (serverless) Android image utility application built with modern Android development practices. It provides precise image compression and format conversion with a stunning, dark-themed Glassmorphic UI.

## Features ✨

- **Precise Image Compression:** Compress images to exact sizes using advanced binary-search compression algorithms.
- **Format Conversion:** Seamlessly convert images to various formats including PDF.
- **120fps UI Experience:** Smooth animations and transitions leveraging Jetpack Compose.
- **Glassmorphic Design:** A modern, premium dark-themed aesthetic that feels native and responsive.
- **100% Offline & Private:** Zero network dependencies. All processing is done locally on your device for maximum privacy and speed.
- **Scoped Storage Ready:** Fully compliant with modern Android scoped storage requirements for secure file handling.

## Tech Stack 🛠️

- **Language:** Kotlin
- **UI Toolkit:** Jetpack Compose
- **Architecture:** MVVM (Model-View-ViewModel)
- **Image Loading:** Coil
- **Image Processing:** Native `ImageDecoder` APIs
- **Concurrency:** Kotlin Coroutines & Flow

## Setup Instructions 💻

1. Clone this repository:
   ```bash
   git clone https://github.com/kartikpro9599-hash/imgCompressor-Formattor.git
   ```
2. Open the project in Android Studio.
3. Connect your Android device or start an emulator.
4. Build and Run! 

> **Note:** The `local.properties` file is intentionally excluded from version control. Android Studio will automatically generate it for you upon opening the project.
